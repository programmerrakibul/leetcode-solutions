using GitHub Actions.

(PostgreSQL)**.

### 📌 About

### ⚙️ Auto Sync Setup

This repository is automatically updated using the
[leetcode-sync](https://github.com/joshcai/leetcode-sync) GitHub Action.

- New accepted solutions are synced periodically
- Manual trigger is also available from the **Actions** tab
- Only accepted submissions are uploaded
